📖 Project Overview

EduAI Nexus is a full-stack MERN Stack web application designed to provide a complete online learning experience for students, instructors, and administrators.

Students can browse and enroll in courses, make secure online payments, access study materials, attempt mock tests, interact with an AI Study Assistant, track learning progress, receive notifications, and download course completion certificates.

Instructors can create and manage courses, upload notes, organize learning resources, monitor enrollments, and manage educational content.

Administrators have complete control over users, instructors, courses, revenue, approvals, notifications, and overall platform activities through a comprehensive Admin Dashboard.

This project demonstrates practical experience in integrating multiple real-world technologies including AI, payment gateways, cloud storage, PDF generation, notifications, authentication, analytics, and full-stack deployment.

💡 Why This Project?

Modern education requires an intelligent and centralized platform that simplifies online learning for both students and educators.

EduAI Nexus addresses this challenge by providing a smart digital learning ecosystem where students can access high-quality educational content, instructors can efficiently manage their courses, and administrators can oversee the entire platform.

The application combines AI-powered assistance, secure payments, digital certificates, assessments, and role-based dashboards to deliver a complete learning management solution.

⚙️ Installation
Clone Repository
git clone https://github.com/Janhvi7105/eduai-nexus.git

cd eduai-nexus
Backend
cd backend

npm install

Create .env

PORT=5000

MONGO_URI=YOUR_MONGO_URI

JWT_SECRET=YOUR_SECRET

RAZORPAY_KEY_ID=YOUR_KEY

RAZORPAY_KEY_SECRET=YOUR_SECRET

GEMINI_API_KEY=YOUR_API_KEY

BREVO_API_KEY=YOUR_API_KEY

EMAIL_FROM=YOUR_VERIFIED_EMAIL

CLOUDINARY_CLOUD_NAME=YOUR_CLOUD_NAME

CLOUDINARY_API_KEY=YOUR_API_KEY

CLOUDINARY_API_SECRET=YOUR_API_SECRET

Run Backend

npm run dev
Frontend
cd frontend

npm install

npm start
